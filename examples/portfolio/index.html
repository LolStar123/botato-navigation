what Botato is doing

Botato reads walkable terrain, searches for a route and keeps space between the character and walls. If the terrain changes, it plans again before continuing. The browser runs the same three-stage approach: a wall-distance field, eight-direction A* with a clearance penalty, and collision-checked route smoothing.

These three terrains are authored examples, not captured game maps. The public reference folder contains the original C# router and smoother. This sandbox needs no game process or account.

Keyboard: focus the terrain, use arrows to move the destination, then Enter. Drawing replaces the route immediately. Clearance is a route preference; it is not a guarantee that every narrow passage meets that margin.
